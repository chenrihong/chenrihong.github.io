# 08.检测表单字段是否被修改

:::info[常用函数]

202602251518000381186

给核心平台的单子，期望实现获取表单某个字段是否修改的功能脚本，包含修改状态（是、否）、修改前内容、修改后内容。应用在表单区、按钮区。
:::


## 函数名

| 函数名 | 功能 |
| ---- | ---- |
| this.isFormColModified | 判断表单字段是否被修改 |



## 示例1

```js
this.isFormColModified({
    formid: '1681962108052',
    col: 'theme_color_name',
    callback: (isModified) => {
        console.log(isModified);
    }
})
```

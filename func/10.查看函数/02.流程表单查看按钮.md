# 02.流程表单查看按钮

## this.rowShowProcessClick

> 配置在行操作按钮中，用来打开查看页面。（控件和按钮会只读）

示例

```js
this.rowShowProcessClick({})
```
 

## otherForm
 
工单编号： 202602120952000187337

| 表单 | 表名 | 主键字段 |
| ---- | ---- | ---- |
| 预算表 | scm_budgets_single | budget_id |
| 论证表 | scm_budget_fea | budget_fea_id |
| 项目可行性表 | scm_ask_project_feas | budget_audit_id |


如果详情页面有多个表单，且主键字段与主表单字段不一同时。可配置 otherForm 参数

```js
this.rowShowProcessClick({
    otherForm: [
        { formid: '1673597292693', pkCol: 'budget_id' },
        { formid: '1683010286014', pkCol: 'budget_id' }
    ]
})
```

### 参数说明

- formid: 表单ID
- pkCol: 父表格输出列列名，且与表单的主键字段相关联。

如列表中查出来字段是 budget_id， 子表的主键名是 budget_fea_id。取子表数据时，要用 budget_id的值。

这个时候，pkCol 要填写 budget_id
